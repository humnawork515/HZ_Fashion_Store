HZ — HAMNA ZAINAB FASHION WEBSITE
===================================

HOW TO RUN
1. Keep the folder structure unchanged.
2. Open index.html in a modern browser.
3. An internet connection is needed for Bootstrap CDN, Google Fonts and the fashion photography URLs.

FOLDER STRUCTURE
- index.html                 Main entry file (root directory)
- css/style.css               Custom responsive styles
- js/script.js                Product data, filters, cart and wishlist logic
- images/hz-mark.svg          Local HZ favicon / brand mark
- bootstrap/README.txt        Bootstrap CDN information

FUNCTIONALITY
- Add products to cart, change quantities, remove items and view subtotal.
- Save/remove wishlist products.
- Cart and wishlist are saved in browser localStorage.
- Product category filters and search.
- Quick-view product modal.
- Newsletter form demo interaction.

IMPORTANT CUSTOMIZATION BEFORE LAUNCH
- Replace the sample product names, descriptions, prices and image URLs in js/script.js.
- Replace hello@hzfashion.pk and the sample WhatsApp number in index.html with your real contact details.
- Replace social profile placeholder links.
- Add your actual shipping, returns and privacy policies.
- This is a static storefront demo. It does not process real orders or payments.
- For live checkout, connect a secure backend / ecommerce platform and a supported payment provider.
- Product images currently load from Unsplash image URLs and therefore require internet access.

BOOTSTRAP
Bootstrap 5.3.3 CSS and JavaScript are linked from the official jsDelivr CDN in index.html.
This avoids bundling a second-party vendor copy in the starter package. If you need an offline copy,
download the official Bootstrap 5.3.3 compiled CSS and JS distribution into this folder and update
the CDN references in index.html to the local paths.

DESIGN UPDATE
The site uses a refined dark-luxe theme: charcoal backgrounds, warm ivory typography and muted antique-gold accents.
